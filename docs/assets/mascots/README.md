### Source archive handling

The supplied Railee Adams archive also includes an editable PSD source and a file named `Phil Mascot - With BG Png.png`. Inspection found that the latter is byte-for-byte identical to the JPEG despite the `.png` extension. We therefore retain the correctly named JPEG as the background version and the genuine RGBA PNG as the transparent version. The large editable PSD is not needed for routine documentation rendering and is not checked into the source tree.
