## What this candidate actually implements

`src/Phil/Verification/P8SemanticFormCodec.hs` is an isolated **non-accepting diagnostic codec** on the *actual* native Haskell `SemanticForm` and `GenericApplicationIdentity` types. Four constructor tags preserve recursive `Atom Text`, ordered children, unordered `Set SemanticForm`, and records with `Map Text SemanticForm`. Generic D/V/Q/M roles use distinct tags. Canonical decimal lengths count **UTF-8 bytes** rather than Unicode code points. Encoding uses existing native `TextEncoding.encodeUtf8` and native `Map.toAscList`/`Set.toAscList`; decoding uses strict `decodeUtf8'` and requires ascending unique keys/members rather than silently deduplicating an adversarial byte stream. All count fields are decoded as arbitrary-size `Integer` and checked against actual remaining bytes rather than accepting overlong formats or imposing a new fixed-width size limit. Actual finite values from the existing native producer `deriveGenericApplicationIdentity` are round-tripped.

The P8-owned executable test exercises recursive nested forms, empty structures, U+00E9, U+1F642, embedded NUL, decomposed U+0065+U+0301, Unicode keys, canonical Map/Set insertion independence, ordering-sensitive children and sampled noncollision, plus rejection of invalid UTF-8, incorrect/noncanonical lengths, wrong role/constructor tags, duplicate/unsorted Q/record/set keys, impossible counts, truncated or trailing data. The codec is **not** exposed by the library cabal manifest or installed in an accepting source/stage/release producer: no authority is granted by simply having a correct parser. The real Upload/Steve checked source/stage/release regression is rerun **separately**, without pretending this codec has already mapped those accepted objects.

The P8 Rocq 9.2.0 module `P8CanonicalFormModel.v` models **octet-sequence payload shapes**, not arbitrary Unicode scalar strings. It proves disjointness of model constructors and D/V/Q/M roles, and `StronglySorted lt -> NoDup` given irreflexive `lt`, with `Print Assumptions` and `rocq check`. These small real proofs are independently typed and explicitly **do not establish a correspondence to the native Haskell codec**. Hosted GHC 9.6.7 `-Wall -Werror` validates this concrete native code and positive/negative examples. Finite tests and a conditional model are **not** a mathematical injectivity/round-trip theorem for the full native domain. This partial boundary must not be advertised as accepted authority.
