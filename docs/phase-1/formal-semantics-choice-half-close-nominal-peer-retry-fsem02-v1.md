# FSEM-02: source choice nominal peer refusal after committed half-Close

**Status: bounded, non-normative** (issue #1613). This follows the wrong-outcome source-choice half-Close/retry slice #1751 and checks a different gate: **externally supplied protocol instance and role**, not End outcome. No new source syntax, production authority or TCB.

The existing production executable `test/Phase1FSEM02SourceJointChoiceMain.hs` parses complete accepted Go/Done and Cancel/Cancel Client Select and Server Offer sources, checks projection, activates a separately supplied two-process Core network, and executes the checked Select/Offer and either first terminal End Close. A foreign instance, foreign role, or both presented to the still-live peer must reject as the exact `EndpointClosureProtocolError` carrying `ProtocolInstanceMismatch` or `ProtocolRoleMismatch`; **instance rejection precedes role rejection** when both are wrong. A previously retired occurrence must reject as exact `EndpointClosureOccurrenceUnknown` even with both nominal fields wrong, because occurrence lookup happens first. The accepted first Close cannot roll back: the peer's Core process context and owner, and a borrowed affine spectator, remain unchanged. A properly authorized second Close converges to the same **entire** process state in either order for both choices. The test also checks the minimally rejected complete source offer `test/fixtures/fsem02-source-offer-replay-v1/wrong-body.phil` as precisely `GrammarV1ComponentOfferArmBodyUnsupported`, not an arbitrary parser failure.

`proof/Phil/Core/FSEM02ChoiceHalfCloseNominalPeerRetry.v` models external nominal grants as two independent boolean facts. It proves exact instance-before-role refusal, preservation of the already committed finite owner ledger and spectators, and conditional retry convergence under the same explicit two successful-close premises as the terminal diamond. A refused model trial **does not return a successful peer step**; `None` includes nominally accepted trials outside this finite refusal model. No new `Admitted`, `Axiom` or `Parameter`.

The proof is **conditional**, not a native Haskell-to-Rocq simulation. Selected source choice, protocol instance/roles, activation, explicit terminal outcomes, scheduler/environment steps, architecture-root selection, disposal and assurance authority remain external premises. Not a complete formal operational semantics, universal preservation theorem or normative graduation.
