## Selected existing source competence

The [real source adapter](../../src/Phil/Surface/GrammarV1/SourceAffineIfJoinResource.hs) parses Grammar-v1 declarations and performs actual nominal Affine Permit admission, type/mode/lineage checks, lexical branch resolution, production scope pruning and `Core.Context.joinContinuing` before checking the post-join source continuation. A nominal Permit's Affine mode depends on an **externally admitted lifecycle attestation**; source spelling is not sufficient authority.

The new [strict independent native driver](../../test/Phase1FSEM01Corr6MixedJoinMain.hs) re-runs six existing authentic source cases: asymmetric Affine disposal, retained Affine owner on both sides, two sibling same-spelling branch locals with distinct semantic identities, an Unrestricted branch-local declaration pruned before joining, a live Linear local that fails scope cleanup **before any join**, and an Affine permit stale use that fails **after a valid join**. It checks exact Γ/A/Δ/loan maps and branches against a new finite **list-based**, independently computed mixed join, rather than using production Map.intersection to construct its answer.

Adversarial controls reject active left or right loans, unexpected Unrestricted/Linear map disagreements, conflicting Affine owner types, duplicates across zones, malformed loan ownership and fabricated joined Affine successors. The focused GHC run also **reexecutes** the independent, previously merged parsed-source J-1/J-2 terminal-arm driver (`Phase1FSEM01SourceBranchJoinMain.hs`) to enforce exact one-terminal predecessor exclusion and the rejection of both-terminal branches. These terminal fixtures do not falsely claim the nominal Affine adapter itself admits arbitrary terminal syntax. The first-order refusal order is native: active loan first, U mismatch, Linear mismatch, Affine intersection/type mismatch. The Affine check intentionally visits the **first** continuing predecessor's active bindings; an owner dropped there cannot be resurrected or trigger a late error from a second-branch mismatch.

## Independently decoded original-source bytes

The native checker driver additionally emits **six versioned ASCII transcripts** after rechecking each original Grammar-v1 declaration, the independently admitted nominal Permit mode, exact declaration-rooted flag/permit/payload Core names and all reached post-pruning predecessor states. The wire header is `PHIL-FSEM01-CORR6-V1|` followed by **eight canonical length-framed fields**: source SHA-256, exact function root UTF-8 hex, the three real source binder-name UTF-8 hex identities, each predecessor's observed full bounded U/A/L/loan shape and the production outcome (empty/retained join, pre-join LinearCompletion or post-join stale-Affine StructuralUse).

[The strict Rocq source decoder](../../proof/Phil/Surface/SurfaceSourceMixedJoinWireCorr6.v) reuses the proved v1 observation framing rather than trusting the Haskell outcome label as a join result. It derives the canonical two-predecessor **same-type bounded model contexts** from the verified source identities and state tags, executes the finite join and checks the observed Affine retention/dropping profile. `PREJOIN_LINEAR` never constructs a joined successor, and `POSTJOIN_STALE` is a separate checked-source error *after* a successful resource join. The decoder is proved to reject wrong versions and produce only valid decoded profiles; it is not a proof of arbitrary Haskell source-state serialization.

[The independent source-wire validator](../../scripts/fsem01_corr6_source_join_witness.py) checks exact source SHA-256, UTF-8 root/binder encodings with source-declared ordinals, profile and input/output status, strict framing, corpus completeness and multiple malicious mutations. It passes the actual raw Haskell-emitted bytes into a generated Rocq witness, compiled with `vm_compute` over the bounded source-verified common types. This profile uses the reflexive comparator on genuinely same-type checked source entries; it is **not** an alternate generic `Ty` equality oracle. The general computed model's soundness theorem separately requires the iff-reflection law for type equality.

CI must independently succeed in four focused jobs: compiled general Rocq model and extensional soundness, strict native checked-source and source-wire producer, standalone versioned Rocq decoder, and **dependent exact-source-artifact compiled Rocq replay**.

## Rocq model and exact boundary

[SurfaceFiniteMixedJoinCorr6.v](../../proof/Phil/Surface/SurfaceFiniteMixedJoinCorr6.v) computes total finite join decisions across Γ/A/Δ/loans. The type equality oracle is **a parameter to the function**, with a required *sound and complete equality reflection law* for model correspondence. That law is not silently assumed as part of Haskell's `Eq Ty`, nor is generic Unicode Text/Rocq String equality discharged by checking source fixtures.

Its proof obligations include universal lookup-based U/Linear equality equivalence, exact possible Affine retention, model-joined output and rejection/no invented successor. Its result is limited to **two continuing predecessors**; terminal, rejected or failed-source predecessors are not equivalent to a successful continuing branch. The native driver uses the previously accepted source path and treats the live Linear branch-local failure as a **pre-join** rejection, not a Core join failure.

The model proof and native source evidence must pass strict Rocq 9.2 and GHC 9.6.7 -Wall -Werror CI with a full exact-head PR census, a fresh post-ready claim guard, protected expected-head squash merge and independently trusted exact unique-claim release. The general source↔Haskell Map/Set/Text↔Rocq refinement remains a separate, open obligation. This slice improves R10/R11/R15, but does not cover arbitrary source match, nested/dependent join telescopes, unbounded control flow or FSEM-05's full extracted interpreter.
