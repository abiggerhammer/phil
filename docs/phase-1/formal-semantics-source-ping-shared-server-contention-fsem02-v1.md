Unlike the four disjoint participant case, these two communication requests cannot both complete sequentially. The other Client stays at its original source-derived Send head. The fourth activated spectator's full affine owner and active shared-loan state stays unchanged. Both alternate schedules preserve the exact four-key population. Neither rejection returns a successor map.
