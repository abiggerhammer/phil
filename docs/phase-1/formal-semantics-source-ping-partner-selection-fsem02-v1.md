# FSEM-02: externally chosen typed Ping partner selection

**Status:** bounded, non-normative production source/Core trace regression and four conditional Rocq 9.2 finite-ledger lemmas. Tracks [#1613](https://github.com/abiggerhammer/phil/issues/1613) and extends the [stale joint Ping prefix slice](formal-semantics-source-ping-mixed-prefix-stale-joint-ping-fsem02-v1.md).

## Judgment and external inputs

The accepted [Grammar-v1 Ping program](../../test/fixtures/fsem02-protocol-progression-v1/accepted.phil) supplies exact typed Client Send and Server Receive predecessor names, U8 message types, End/Done continuation heads and distinct source successor binders. The minimally rejected [stale-Close source](../../test/fixtures/fsem02-protocol-progression-v1/stale-close.phil) must reject with **`GrammarV1ComponentSendCloseCloseMismatch`** (expected `done`, actual `endpoint`).

The process-network root, six activated process identities, protocol instance and roles, eligible pairing/partner selection, scheduler, terminal disposal rights, environment and assurance remain **explicit externally provided premises**. Source syntax does not confer authority to choose another process as communication partner. This test observes the already implemented `checkProcessCommunication` when the external harness chooses each of the six bijections of three activated Client instances onto three activated Server instances with the same checked protocol instance and dual session heads. A permissible finite checker transition is a joint synchronous Send/Receive that atomically consumes exactly the chosen pair's linear predecessors, creates their distinct End successors, and leaves all unchosen participants' endpoint/resource contexts unchanged. It is not a validation of independently authorized architecture-level pairings.

## Executable production evidence

The [strict source/Core Haskell driver](../../test/Phase1FSEM02ProtocolProgressionMain.hs) runs each of **3! = 6** externally selected bijections, all **3! = 6** orders of their three rendezvous, and all **6! = 720** terminal Close orders: **25,920 accepted terminal schedules**. Each must converge to the same exact six-process endpoint/owner map. After the first selected rendezvous it additionally attempts (1) reusing its consumed Client with an unchosen Server and (2) reusing its consumed Server with an unchosen Client. Each pure attempt must reject with exact `RendezvousEndpointNotOwnedByProcess` and the original process/predecessor, without mutating any other participant; the actual valid suffix still replays. The independently borrowed affine spectator is preserved.

The existing **13,440 legal mixed Ping/Close schedules**, **806,400 rejected Close probes** and **302,400 stale original-pair joint Ping probes** remain active, with their exact diagnostics and legal replay invariants. The 25,920 new terminal-order cases extend *partner selection*, not the set of eligible source-level constructs.

The [Rocq module](../../proof/Phil/Core/FSEM02PingPartnerSelection.v) establishes four conditional abstract finite-ledger laws: accepting a healthy externally chosen peer, preventing rematch by a consumed Client or Server, and preserving an independent third participant. These laws are **not** a general proof of all Haskell transition cases, partner authorization, native `ProcessKey` representation, Haskell↔Rocq refinement, source operational completeness, fairness, liveness, deadlock freedom or global FSEM-02 completion. `SessionStep.v` and `ConcurrencySemantics.v` are related but separate abstractions; proof assumptions and source conformance do not silently collapse into their authority.
