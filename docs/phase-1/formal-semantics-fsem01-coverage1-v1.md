## Classification and scope

The [normative concrete syntax](../../grammar/phase1-surface.ebnf) specifies parseable forms, **not semantic admission**. The [syntax-to-semantics reconciliation](syntax-semantics-completeness-v1.md) catalogs the author-controlled choices, while accepted semantic contracts, the Logic Ledger and checker authority decide whether an individual source occurrence is valid. The classifications deliberately separate:

- **bounded** (18 entries): a narrow tested Grammar-v1 source shape with accepted and minimally rejected examples (or a common driver exercising both), real production ownership/typing transitions, conditional Rocq model evidence, and a merged PR. This does not imply universal source-to-native-to-Rocq refinement.
- **gap** (20 entries): a relevant syntactic form or semantic specialization for which a **general FSEM-01 resource bridge is not established**. Existing model/code files may demonstrate partial work but cannot supply missing source acceptance. A negative fixture reporting bounded-adapter **noncompetence** does not establish normative invalidity.
- **handoff** (8 entries): a form or dimension primarily owned by another FSEM family. Its resource interaction may need reviewed composition later; this inventory does not take over protocol, root, effects/assurance, execution, or target authority.
- **explicitly unsupported by accepted semantic authority (zero entries asserted):** would require the precise accepted decision ruling the form out. Neither an absent source adapter nor a `Nothing` competence result is such a decision.

This is an **evidence index**, not a pass rate. Each bounded row names a positive and negative fixture/driver, production Haskell implementation, Rocq artifact and exact merged PR. The references make claims inspectable, not automatically proved by their presence. The authority scope and assumptions of each individual PR remain controlling.

## Decisions and subsequent implementation work

1. **Aggregates and patterns (R08/R09/R14).** Determine accepted semantic domain for nested/recursive tuples, record/sum payloads, record destructuring and projection. For each admitted shape, add a positive and diagnostically isolated negative executable source witness, real owner transitions and a matching bounded Rocq bridge. Existing nested fixtures are *adapter-noncompetence* evidence, never universal source rejection.
2. **Control-state generalization (R10–R12).** #1685 gives two independent Bool join-state slots, #1708 transfers one Linear loop header owner, and #1710 closes one loan before a checked static backedge. None certifies dependent or restricted phi slots, arbitrary match arms, multi-slot loop state, nonempty break actuals, dynamic iteration, or live loans across backedges. Those require distinct source/typing/termination premises.
3. **Callable ownership and scope (R13).** #1712 has 17 parsed-source closure-capture fixtures and genuine Core ownership/loan operations. General closure bodies, strengthened declared modes with independently validated contracts, source-derived recursive SCCs and invocation/callee resource redistribution remain open. Callable effects, authority, assurance and `satisfies C` are FSEM-04 responsibilities.
4. **CORR-1 and exit review.** After resolving the actual admitted source domain, reconcile exact source success/rejection against native Γ/A/Δ/loan contexts and conditional model cuts, including no invented successor on failure. Full admitted Phase 1 execution/extracted interpreter remains FSEM-05, universal stage implementation refinement FSEM-06, normative adoption FSEM-07. Use [issue #1613's six criteria](https://github.com/abiggerhammer/phil/issues/1613) before changing the FSEM-01 checkbox or Logic Ledger/Conformance Matrix.

## Trust and correspondence boundaries

Source parser and declaration-root identity, Haskell `Text` / `Map` / `Set` to Rocq representations, sound concrete type equality, independent nominal Affine attestation, external capability authority, proof-obligation disposition, scheduler/runtime steps, selected-root population and target realization remain explicit assumptions unless specifically discharged by cited individual evidence. This register changes **no grammar, checked semantic contract, TCB, checker behavior or normative inference rule**. It does not adjudicate missing semantic authority by fiat.
