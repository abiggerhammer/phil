# P8-E1 independent diagnostic wire framing and recursive parser — bounded contract

Authorization: https://github.com/abiggerhammer/phil/issues/1770#issuecomment-6893306835 . E1 is 1/2 of a NEW finite P8-E allowance. Both P8-D PRs are already merged. Unused P8-C3 remains stopped on P9; P10 certification remains blocked.

## Executable mathematical scope

New P8E1CanonicalWireModel.v composes the existing, compiled P8-D1 strict Unicode scalar-stream decoder with P8-D2's mutually recursive full finite Atom/Ordered/Unordered/Record representation and its structural constructor order. It defines arbitrary canonical decimal framing of text byte lengths and children, a scanner rejecting leading zeros, exact length-split with remainder, strict UTF-8 text parser, recursive encoder, and an input-length-fueled recursive parser. Records and unordered members must be canonical and strict pairwise ascending according to actual D2 structural order; input wire is not silently deduplicated or sorted. UTF-8 text and record keys remain octet lists, not fabricated numeric Phil IDs.

Independently proved universal properties: p8_e1_take_exact_sound (successful parse consumes precisely the declared number of octets and preserves remainder), p8_e1_take_exact_prefix (arbitrary known-length prefix followed by arbitrary suffix is parsed without loss), p8_e1_parse_text_prefix_conservation (all successfully parsed texts have exact byte-length framing, retained suffix, and D1 validity), and p8_e1_parsed_text_is_strict_unicode (a successfully parsed text has strict canonical D1 scalar stream decode/encode and well-formedness). Every named theorem is compiled by Rocq 9.2, printed for assumptions, and recursively checked by rocq check on hosted CI; no new Axiom or Admitted is permitted. Negative executable examples cover leading zeros, nested truncation, duplicate Set/Map entries, overlong UTF-8, and trailing bytes.

The full recursive encoder/decoder are independently executable, but E1 does NOT claim universal count-encoder inversion, fully recursive decode(encode(x))=x, structural injectivity, generic D/V/Q/M application identities, normalization or correspondence with Haskell library semantics. Those are E2's obligations, provided E1 first protected-merges; an honestly partial E2 will be reported as such.
