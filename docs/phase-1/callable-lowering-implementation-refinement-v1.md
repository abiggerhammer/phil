# CALL-016 implementation refinement v1

`PHIL-CALL-LOWER-IMPL-001` mechanically links the CALL-016 StageContract checker to its certified semantics.

Target representation choice and representation identity do not occur in the projection.

Production now carries the machine-shape coordinate explicitly in both `SourceCallableLoweringFacts` and `TargetCallableLoweringFacts`, closing the correspondence gap exposed by the initial #224 extraction tranche. A dedicated mismatch diagnostic and regression case ensure machine shape is preserved independently of representation identity.

Handwritten Haskell reconstructs the concrete diagnostic selected by a kernel rejection and fails closed if that diagnostic disagrees with the equality projection. A kernel acceptance is returned to the caller only when all sixteen concrete equality facts also hold. Representation choice and representation identity are never inputs to acceptance.

The checked-in `src/CallableLoweringKernel.hs` is the exact Haskell generated by the green #224 Rocq extraction. CI recompiles the CALL-016 implementation-refinement proof, regenerates the kernel, requires byte-identical equality with the checked-in module, typechecks the generated and production paths, and runs the strengthened CALL-016 corpus through the extracted decision.

Rocq proves the extracted decision accepts exactly when all sixteen coordinates hold and proves accepted production decisions refine the existing `CallableLoweringAccepts` relation given the concrete exact-equality bridge.
