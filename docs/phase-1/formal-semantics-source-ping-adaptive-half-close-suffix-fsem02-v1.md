# FSEM-02: adaptive partner reselection after terminal half-Close

**Status:** bounded, non-normative source/Core conformance and four conditional Rocq 9.2 finite-phase lemmas. Tracks [#1613](https://github.com/abiggerhammer/phil/issues/1613), following the [adaptive partner-suffix slice](formal-semantics-source-ping-adaptive-partner-suffix-fsem02-v1.md).

The existing [accepted typed source witness](../../test/fixtures/fsem02-protocol-progression-v1/accepted.phil) must check exact dual `Send U8`/`Receive U8` session heads, distinct old and successor binder occurrences, and terminal `Done` heads. Its [minimally rejected stale Close counterpart](../../test/fixtures/fsem02-protocol-progression-v1/stale-close.phil) must fail with precisely `GrammarV1ComponentSendCloseCloseMismatch` (expected successor `done`, actual predecessor `endpoint`). These source checks do not authorize partner selection, activation or disposal.

The production [Haskell source/Core driver](../../test/Phase1FSEM02ProtocolProgressionMain.hs) first selects each of nine independently authorized Client/Server pairings and commits its atomic typed Ping. It then executes four possible nonempty terminal prefixes: Client End Close only, Server End Close only, and both permitted Close orders. From every resulting prefix it reselects all four ordered pairings of the remaining two free Clients and two free Servers. Finally it executes every valid order of the unclosed terminal Ends: **10,368 checked complete executions** = 9 × 4 × (2 × 120 + 2 × 24). All must reach the identical six-process closed map and retain the separately borrowed affine spectator.

At each prefix the actual checker must reject a spent Client with a free Server or a free Client with a spent Server as exact `RendezvousEndpointNotOwnedByProcess`, before any state advance. It must reject a repeated retired End as `ProtocolEndpointUnknown`; a bad outcome for a still-live End as `CloseOutcomeMismatch`; and a premature Close of any still-unmatched source-derived Send/Receive head as `UnexpectedSessionAction` with the exact head and attempted outcome. The successful later suffix must replay from the same unchanged prefix and preserve exact process and linear ownership state. The previous 1,512 adaptive suffix, 288 rematch and 25,920 complete terminal traces remain covered.

The new [Rocq finite-phase model](../../proof/Phil/Core/FSEM02PingAdaptiveHalfCloseSuffix.v) proves conditional free-pair preservation under two disjoint phase changes, refusal of Retired Client and LiveEnd Server rematches, and unrelated-spectator framing. It uses the prior `FSEM02PingMixedPrefixFault.v` phase abstraction. It does **not** encode native `ProcessKey`, prove the implementation follows that abstraction universally, or establish general `SessionStep.v`/`ConcurrencySemantics.v` simulation. This finite compositional test/model correspondence is the claimed bridge.

**External premises and nonclaims:** accepted binary protocol instance, root, participant activation, external scheduler/bijection choices, nominal role/instance identity, each terminal disposal permission and assurance authority remain external inputs. No new normative grammar, TCB, globally complete FSEM-02, universal Haskell↔Rocq refinement, extracted interpreter, fairness, deadlock freedom or global progress theorem is claimed.
