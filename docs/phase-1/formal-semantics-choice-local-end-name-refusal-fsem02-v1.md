# FSEM-02: exact local terminal End name is required under the right process

**Status: bounded, non-normative** (issue #1613). This is distinct from #1756's swapped *process*-key refusal. After independently parsed accepted Go/Done or Cancel/Cancel Client Select and Server Offer and a real checked two-process Core rendezvous, even the **right live process** must not close its terminal End by substituting the other participant's endpoint name, the already consumed source predecessor name, or an invented name.

The executable `test/Phase1FSEM02SourceJointChoiceMain.hs` exercises production `closeProcessEndpointState` with the real active process identity and each wrong local endpoint. It tests both actual matching protocol-instance/role values and deliberately foreign nominal values, requiring **exact `EndpointClosureOccurrenceUnknown(process, endpoint)` before nominal validation**, with no fallback/accepted successor. The same attempts are checked when both terminal successors are live, after either independent half-Close, and after both End orders. Valid independently authorized End operations still converge to the unchanged full Core state; the opposite live process context and an unrelated borrowed affine spectator are preserved. The suite runs both complete positive Go/Cancel source fixtures and the minimally rejected `test/fixtures/fsem02-source-offer-replay-v1/wrong-body.phil`, asserting `GrammarV1ComponentOfferArmBodyUnsupported`, not an arbitrary parser failure.

`proof/Phil/Core/FSEM02ChoiceLocalNameClose.v` proves that a mismatching local endpoint name under the **correct** process is refused by the conditional finite occurrence-owner ledger, composes the source-choice successful successor with independent wrong-name refusal for both participants and spectator frame, and proves refusal after both separately authorized End-close orders. There are no new `Admitted`, `Axiom`, or `Parameter` declarations. These are finite ledger statements, **not** universal Haskell-to-Rocq source-step simulation or a newly executable reference interpreter.

**Rule and trust boundary:** a terminal End retirement requires a live occurrence `Some(process, endpoint)` matching both the process and exact terminal `Name`. A refused wrong-name call yields no successor; successful independent End retirements consume only the exact occurrence. Source parser/projection fidelity, active process population, protocol instance and role grants, selected branch/terminal outcome, scheduler/environment, independent endpoint disposal, selected root and assurance authority remain external inputs.
