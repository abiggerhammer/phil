# FSEM-02 / source-checked restricted send/receive ownership transfer

**Non-normative; not a new language authority.** Tracking issue [#1613](https://github.com/abiggerhammer/phil/issues/1613). This slice composes existing independently parsed source send/receive carriers with **existing** production Core restricted-message rendezvous. It does not revise Phase 1 EBNF, ADRs, or the trusted computing base. FSEM-02 remains open.

## Exact judgment and external premises

`(senderSource, receiverSource, protocolInstance, senderRole, receiverRole, senderProcess, receiverProcess, network, occurrence, state) --send/receive--> state'`

Here `state` comprises exact protocol/resource contexts and an activation-derived global restricted-owner index. `network`, process keys, nominal protocol declaration/interface identity, independently admitted binary instance/roles (for restricted `Bytes[8]` payloads, **Core requires an explicit external `BoundaryMessageContract` and generic message argument**; a concrete source-declared `Bytes[8]` family is *rejected* by `instantiateBinaryProtocol` as `ProtocolConcreteMessageRequiresBoundaryContract`), and the unique payload `ActivationOccurrenceKey` **must be supplied by an external authority**. They are never inferred by matching source spelling.

The sender must be an exact parsed component body `let done = send payload on endpoint; close done;` and receiver an exact `let (done, received) = receive Bytes[8] on endpoint; close done;` shape. Each source operand, predecessor endpoint, and fresh successor is resolved by the existing declaration-rooted binder scope checkers. The sender's payload binder must be an actual component parameter, with source-declared type checked through `grammarV1CheckedTypeMode`. Its mode must be `Linear` or `Affine`; the receiver's source-written type and checked mode must agree **exactly** with that payload. No guessed opaque or nominal type fallback is admitted.

**Additional exact-binder premise:** Core's checked receive-message binder must equal the *declaration-rooted semantic identity* of the source receive-pattern payload binder, not the source protocol's display-level `value` label. The accepted test supplies an independently authorized generic instance whose message binder has been chosen to match that resolved source binder; this choice is external protocol/source correspondence evidence, **not** a derived authority or a general proof of alpha-renaming. A second, otherwise valid generic instance retaining the literal `Name "value"` must fail with `RestrictedMessageReceiverBinderMismatch`. No binder remapping is silently performed by the adapter.

The adapter `src/Phil/Surface/GrammarV1/ComponentRestrictedRendezvous.hs` builds `SendReceiveRendezvous` and `RestrictedMessageTransfer` with those checked source binder identities and externally supplied occurrence. It invokes production `checkRestrictedProcessRendezvous` once. Success returns **one** successor state in which both dual session heads have consumed predecessor endpoints and replaced them by fresh typed successors; the sender's restricted payload binding is consumed, the exact same occurrence key now points to its source-derived receiver binder, and the receiver gets exactly one corresponding binding. Independent affine spectator keys/resources are preserved. The source `close` statements are shape-checked but **not executed**; `End` outcomes remain obligations for a separate closure transition.

Rejection is `Left` with no successor: unsupported send/receive shape; exact source-binder failure including `GrammarV1ComponentSendCloseCloseMismatch`; sender source type out of competence or nonrestricted mode; source written receive type/mode mismatch; or the **original** production `ProcessRendezvousError` (unknown/stolen payload owner, stale source endpoints, incompatible session heads, duplicate receiver binding, incorrect roles/instances, or `RestrictedMessageReceiverBinderMismatch` for a non-corresponding authorized protocol binder). No error is translated into success.

## Executable evidence and bounded Rocq correspondence

`test/fixtures/fsem02-restricted-source-transfer-v1/accepted.phil` is a complete parsed source with `Bytes[8]` send/receive dual sessions and explicit architecture clauses. `rejected-stale-close.phil` changes only the sender's `close done` to `close endpoint`, which must fail with **exact** `GrammarV1ComponentSendCloseCloseMismatch`. The executable `test/Phase1FSEM02RestrictedSourceTransferMain.hs` checks the richer source protocol family, confirms that its uncontracted concrete restricted message cannot instantiate, separately instantiates a generic `ProtocolParameterType` with an explicit boundary contract, activates a fully explicit Core process network with source-derived binder names, then constructs the exact owner ledger through `activateProcessState` and `communicationStateFromActivation`. It replays accepted/negative source and Core transitions, verifies exact payload and endpoint owner-occurrence identities, predecessor consumption, receiver insertion, terminal heads, deterministic replay, and spectator preservation. These source components have **not** been fully admitted by one source architecture/root checker: authority for their binary instance, process network and activated occurrences is explicit test input, not conferred by parsing the architecture text.

`proof/Phil/Core/FSEM02RestrictedSourceTransfer.v` contains a separate functional owner-map model linked to `FSEM02StatefulSourceChoice.v` and its prior `SessionStep.v` progression model. Machine-checkable conditional theorems state source/message/head rejection, missing payload rejection, and that every accepted modeled transition preserves the two endpoint occurrence identities, transfers the precise payload occurrence once, and leaves *all* unrelated owner keys unchanged. The proof takes checked source shape/message admission/head validity, unique owner-index representations and process identity as premises. `ConcurrencySemantics.v` independently establishes restricted rendezvous admission/owner facts; this is **not** a global theorem that the production Haskell implementation refines the Rocq model.
