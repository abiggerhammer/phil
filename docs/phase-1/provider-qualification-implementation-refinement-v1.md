# PROV-001–005 implementation refinement v1

`PHIL-PROV-QUAL-IMPL-001` is the mechanical production-correspondence migration for the already-certified stateless provider qualification core.

Provider qualification is the first migration with nested finite maps: public operations, explicit operation correspondences, implementation entries, implementation outcomes, and mapped public outcomes. Rather than re-encoding `Data.Map` semantics ad hoc inside the provider checker, this tranche factors a reusable extracted finite-association support kernel.

The support kernel provides:

- exact pairwise key-domain comparison for canonical association lists;
- exact association-list lookup; and
- universal finite Boolean traversal.

Rocq proves key-domain comparison equivalent to equality of the finite key projections when the supplied concrete key equality is exact, proves lookup soundness (and completeness for unique-key lists), and proves finite Boolean traversal equivalent to `Forall`.

The production adapter will use `Map.toAscList` plus fail-closed `Map.fromList` round trips before passing lists to the extracted kernel. Exact equality/ordering of concrete Haskell keys and `containers` map semantics remain named primitive TCB components.

This first support tranche does not yet earn `Implementation Refined`. A following commit will define/extract the actual PROV-001–005 operation/outcome traversal on top of these helpers, compose per-operation callable acceptance with the already `Implementation Refined` CALL-012 checker, bind exact generated bytes into production, and require byte-identical regeneration.
