## Actual selected subject, no lossy identity

The new admission module calls the accepted prepareSelectedSteveGet on the
original checked ordinary-Surface input. Its sealed descriptor supplies the
original K/I, free ContentId type, read/digest spans and exact selected provider
revisions. The actual Core is the existing steveCoreProgram (the complete native
program, not a hand-constructed model function). Native Map validity is checked
before lookup or projection. The opaque RuntimeChoicePayloadPlan is recertified
on that same native object, including all four plan sites. The joint selector
is private and positional.

The proof-extracted selector is actually called during admission on a direct
typed structural reification of the native selected function and complete plan:
native map and embedded keys, all declared value roles/storage identities,
entry, every reachable/unreachable block, complete ordered operations and
operands, raw choice-site key, exact control arms, exact plan map and embedded
site keys and payload target/value. UTF-8 bytes are retained, never a content
digest or Show as identity. Unsupported native constructors reject. The
Rocq reflection theorem gives equality of this typed reification to the exact
finite contract; the Haskell full native-program equality and independent
recertification additionally bind the complete Steve context. Concrete selected
AST/provider representation, native containers, UTF-8 conversion, extraction
and Haskell-to-Rocq adapter fidelity remain separately reviewable boundaries;
there is no theorem about arbitrary Haskell Eq, Map, IO or Unique implementation.
The original source blob and actual compiled proof and generated kernel are
pinned in CI. The native selector is extracted into an ephemeral artifact
from the checked proof; there is no additional checked-in generated path.

## Mathematical target-to-source proof target

The new Rocq rule is guarded by the extracted exact native typed selector and
reads the actual selected block/choice/plan arm, target, operand list and
cleanup operation. Its target state retains the found payload through
digest/release. It imports the unchanged **labelled** FSEM-05 source step rules,
and constructs labelled source histories; the older unlabelled selected_steps
closure alone cannot prove payload identity. The fixed-E head is consumed once
for the selected read/digest. Matching external labels preserve the original
payload and digest decision; the rule carries the selected binding (K/I,
occurrences, qualifications, ContentId) in the qualified reply. A nonfound
source Unit may be delayed by the target's final empty block. Diagnostic erasure
and source open/close administrative segments are explicit.

Named theorems cover exact typed-selector reflection, exact choice guards,
labelled replay soundness, bounded step lifting, composed fixed-E history
inclusion, phase lifecycle inheritance, rank decrease, no unanswered provider
step, exact found payload, and exact abstract origin-pair comparison. The focused repair adds a distinct invocation-bound dynamic check. The static
Core rule's key predicate remains structural only; the new full
binding_matches_native compares the independently admitted source+invocation
context with every qualified reply (full spans, both operation/interface/
implementation identities and exact invocation ContentId). SourceSpan point
fields are encoded separately. The new checked segment theorem states an actual
represented target step, exact E consumption and a specified qualified labelled
source segment with at most two source steps and preserved observations.

The source side of the checked producer calls the SAME privately held selected
FSEM-05 invocation; it checks actual returned step results against per-call
snapshot deltas and the actual world active status. The target computes its
step before consulting the source. A receipt is only issued after the extracted
checker accepts the real pre/post target frame reifications, fixed E suffix,
actual consumed reply, target observations, actual source input labels and
private source observations. The source delta is not a caller assertion and
the checker tests the specified realized segment rather than choosing an
existential alternate source trace.

The payload table is taken once from the immutable invocation E (exact UTF-8
names); payload_index_sound and equal_payload_index_preserves_bytes show
the code's exact table lookup property. The model's origin IDs are local
indices obtained by applying unique_index to equality comparisons with
the actual opaque issued identities, not by encoding Unique or a hash.
unique_index_sound and unique_index_only_match show that the index selects the
one actual equality slot. The checked private map pairs target and source
origins and complete issued/retired sets, including across invocations; the
target now retains actual retirement order. A separate-world origin cannot
select an entry in the receipt's opaque table. These are finite checked
representation and source-realization controls, not a formal semantics of
arbitrary Haskell Eq, Text, IORef, Map, GHC or extraction. The independent
review must judge the fidelity of the actual adapters and private producer,
not assume it from the mathematical theorem or from green tests alone.

## Build and ownership

RuntimeChoicePayload and SystemsWitnesses are established standalone src
modules, not entries of the main-library Cabal manifest. The new selected
reference module is compiled in the existing standalone -isrc convention with
the ephemeral extracted kernel, so **no Cabal registration or extra package
closure is required for this bounded reference evidence**. The main library is
built with unsuppressed -Werror as a separate control. No warning suppression,
new checked-in generated file, extra manifest registration, or package/TCB
change is proposed. Exposing this experimental reference module as a packaged
library would need an explicit separate decision and closure review.
