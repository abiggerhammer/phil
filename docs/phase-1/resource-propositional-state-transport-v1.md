# RES-010 — Propositional transport at state boundaries

Phase 1 state boundaries do not enlarge definitional equality.

If a resource index matches a post-state slot only propositionally, the source resource must first cross an explicit checked Core transport justified by accepted equality proof evidence. The resulting transported owner may then participate in ordinary state projection under the target subject/index correspondence.

The RES-010 conformance fixture therefore checks both sides of the boundary:

- an untransported owner presented directly to the target state slot is rejected; and
- Core `VTransport`, supplied with an explicit reusable proof of the required equality, preserves linear ownership while producing the target type, after which the transported Systems owner is accepted by the normal state-projection checker.

This is deliberately an integration contract between existing Core transport semantics and Systems state projection. It does not add a second equality relation or a proof-token escape hatch to Systems IR.
